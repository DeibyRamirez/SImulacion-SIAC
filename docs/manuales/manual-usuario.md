# Manual de Usuario — SIAC

## Acceso

1. Abrir http://localhost:3000
2. Ingresar correo `@uniautonoma.edu.co` y contraseña
3. El sistema redirige al panel según su rol

## Roles

### Cargador
- Descargar plantillas oficiales
- Subir evidencias (PDF/Excel) con metadatos
- Ver estado de sus documentos
- Corregir rechazos

### Revisor
- Bandeja de borradores pendientes
- Aprobar o rechazar con observaciones
- Notificar al cargador automáticamente

### Administrador / Par académico
- Panel de programas con semáforo
- Ver solo evidencias validadas
- Dashboard de métricas (Power BI o Recharts)
- Control de vigencias y alertas
- Gestión de estructura normativa

## Flujo típico

1. Cargador descarga plantilla
2. Diligencia documento externamente
3. Sube evidencia con programa, periodo, factor e indicador
4. Revisor revisa y aprueba o devuelve
5. Administrador supervisa avance por programa

## Semáforo de vigencias

| Color | Significado |
|-------|-------------|
| Verde | Vigente (>30 días) |
| Amarillo | Próximo a vencer (≤30 días) |
| Rojo | Vencido |
